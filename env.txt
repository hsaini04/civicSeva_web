# CivicSeva Frontend Environment Setup Guide

To get the frontend running on your local machine, you need to create a `.env` file in this directory (civicSeva_web).

1. Copy `.env.example` to a new file named `.env` OR just create a new `.env` file.
2. Add the following variables to your `.env` file:

```env
VITE_API_BASE_URL=http://localhost:8000/api/v1

# ⚠️  Replace with your actual Gemini API key
# Get one from: https://aistudio.google.com/app/apikey
VITE_GEMINI_API_KEY=your_gemini_api_key_here

# Gemini model to use (options: gemini-1.5-flash-latest, gemini-2.0-flash, gemini-2.5-flash-lite)
VITE_GEMINI_MODEL=gemini-2.5-flash-lite
```

### Things you MUST change:
- `VITE_GEMINI_API_KEY`: You cannot use the placeholder. You must generate your own free API key from Google AI Studio and paste it here, otherwise the Smart Assistant (CivicAssist) will not work.
